# Preparation Attempts and Preserved Findings

- **Base startup/login defect:** Base `6543fdd` validates support passwords in `.env` but does not pass them to the API child process; `app.py` reads only process environment. Candidate startup maps the four local demo credentials to the API process and restores them before starting Vite. Actual local API login with the `.env` value and Session creation passed after the change. Password values are absent from logs/evidence (`SECRET-SCAN.json`).
- **First `npm ci`:** failed with Windows `EPERM` in the shared `D:\node.js\node_cache` and left an incomplete install. Retried `npm ci --no-audit --no-fund` with a task-specific temporary cache; 147 packages installed, `npm run build` passed. No dependency or lockfile was changed.
- **First pytest run:** default pytest Temp under the user profile failed to create its base directory (`WinError 5`); raw log is retained in `TARGETED-OFFLINE-REGRESSION.log`. Re-ran with a fresh isolated `.runtime\pytest-r2-ar03-user-test-ready-01*` path; **44 passed** in `TARGETED-OFFLINE-REGRESSION-D-RUN.log`.
- **First SSE close assertion:** handshake succeeded and Stop exited API/Vite, but the check read only one byte from an already-buffered event and incorrectly classified that as not closed. The first result remains in `STOP-SSE-PREFLIGHT.json`. The corrected check drained the response through EOF after Stop, confirmed no listeners remained, and confirmed Session persistence after restart; see `STOP-SSE-PREFLIGHT-GREEN.json`.
- **Initial cross-Tenant command attempt:** PowerShell/Python quote escaping failed before the authorization request; the `finally` path stopped both services. The corrected direct API request returned HTTP 422 for a fixture order registered only under tenant-b and left TaskBinding/Message counts unchanged; see `S3-SCOPE-HTTP-PREFLIGHT.json`.
- **Live-mode startup:** blocked as expected before starting listeners because this isolated DB has no Runtime Grant and required Provider key/config/price fields are absent. See `RUNTIME-PREFLIGHT-NO-GRANT.log` and `LIVE-START-BLOCKED-NO-GRANT-RETRY.log`. No Provider request was made.
- **Evidence export without a Grant:** exporting the empty offline preflight Session returned `RUNTIME_GRANT_NOT_PROVISIONED` from the existing spend-summary dependency; no export file was written. The guide limits this exporter to post-authorization Live sessions and uses `runtime_admin.py summary` before a Grant exists. No exporter code was changed.

These are preparation and harness findings only; historical R2 RED/Gold evidence is unchanged.
