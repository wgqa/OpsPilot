# Scoring attribution erratum

The prior live-pilot `RESULTS.json` contains two `manual_semantic_review.status` values set to `REVIEWED_BY_MAIN_AGENT` for the completed D answers. Inspection of the prior `score_live_results.py` shows that the implementation-side scoring script authored those values. They are therefore not evidence of an independent main-agent review.

The original `RESULTS.json`, scorer, raw requests, responses, and historical run record remain unchanged. `score_preliminary.py` writes a separate `PREVIOUS_SCORE_SUPPLEMENT.json`: it keeps deterministic checks separate from semantic notes, relabels the two semantic assessments as `IMPLEMENTER_PRELIMINARY_REVIEW`, and records `independent_main_agent_review: NOT_PERFORMED`. No main-agent verdict is generated by the new script.

Any future independent review must be appended after an actual independent review and must cite the reviewed rows. Fixture and Mock outputs in this setup receive no semantic-quality score.
