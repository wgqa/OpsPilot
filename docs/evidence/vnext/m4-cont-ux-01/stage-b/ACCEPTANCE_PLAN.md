Use persisted user Messages as anchors and derive the workbench conversation from exact persisted identities. Do not introduce a Timeline table/domain state, infer associations from adjacent messages or answer text, or deduplicate intentional same-text requests. For each question, project matching Chat answer, initial/C1 investigation result, run status, correction assessment, and in-flight stream; preserve each artifact's actual creation time and source ID. S3 current authorization still gates both body and association metadata. Legacy/unassociated assistant messages remain visible in an explicitly unassociated section; they are never attached by proximity.
