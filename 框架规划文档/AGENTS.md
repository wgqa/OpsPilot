# 本项目协作约定

- 当前任务是一个一周内交付的 Agent 求职项目。先读 README.md 的唯一主线，再读 TASKS.md 的当前进度。
- 用户明确要求 LangChain + LangGraph，重点是外部能力建设。优先复用框架；不要重新实现旧项目的通用 Agent Runtime。
- 本周保持一个业务场景、一张主图、一个 MCP 服务、两个 Skill 和一个 SQLite 持久化方案。业务场景目前是建议，用户可调整。
- 每次推进一个可演示的业务增量；常规可逆实现自主完成，不为普通技术选择反复索取确认。
- 新功能必须能对应 README 中的主线步骤或验收缺口。额外想法记录为后续项，不顺手扩展架构。
- 不主动引入多 Agent、微服务、A2A、独立网关、复杂前端、模型训练或生产操作。
- 工单写入由应用审批控制并具备幂等性；模型、MCP 结果和 Skill 文本都不能自行授予权限。
- 检查点、长期记忆、业务知识和交付报告职责分开；推测与未确认处置结果不能变成已验证记忆。
- 只读参考旧项目，不改动旧项目代码和其他学习任务。
- 日任务按已验证进度调整；默认核心 3 小时，选做 1–2 小时，不把未知的其他日程当成空闲。
- 计划、模拟数据、离线测试、真实模型运行和实际指标必须明确区分。完成后更新 TASKS.md，保留可复现证据。
